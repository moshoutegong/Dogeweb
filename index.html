BEHIND THE TOOLS / 本站软件来源

从工作里的小麻烦，
到电脑里的小工具。

这些软件的起点，都很简单：
工作里刚好需要，却总找不到顺手的办法。

想把抖音、小红书的视频素材保存下来，不带水印；想录一段屏幕，把操作讲清楚；想从小视频里截取一个片段，转成 GIF，插进公众号文章里。

日常办公中，这些事情不大，却常常让人花时间找工具、试方法。这个小站，就是想把能解决这些问题的软件整理在一起，让你需要的时候，刚好有个顺手的选择。

本站的软件实践，主要从 GitHub 等平台的开源项目出发，结合自己的需要，借助 Codex 进行定制、修改和完善。各款软件的具体来源与许可，见对应的项目说明。

作者的话 / 从想法到成品

以前，“想做”和“做出来”之间，
隔着一道技术的墙。

现在，这道墙正在变薄。即使不懂代码、不懂 UI 设计，也可以借助 AI 智能体，从一次对话开始：把需求说出来，试一试，发现问题，再调整。一轮轮下来，原本只停留在脑海里的想法，也有机会成为真正能用的软件。

这并不意味着什么都不用学。你仍然需要判断结果、理解问题，也需要愿意花时间钻研。只是，起点不再一定是先掌握一门编程语言，而是先弄明白自己到底想解决什么。

知道自己要什么，
知道怎么把它说清楚，
知道卡住时该问什么。

这是我在做这些软件时，越来越看重的能力。把自己的思考看清楚，再把问题一步步拆开——对我来说，这就是元认知落在实践里的样子。这个小站既是工具箱，也记录着我和 AI 一起把想法做出来的过程。

DOGEFETCH / V1.9.2

DogeFetch · 视频下载器

适用 Windows 10 / 11 64 位。完整便携包内含 .NET 8、yt-dlp、Deno、FFmpeg 和 FFprobe。

开始使用

  1. 将整个压缩包解压到普通文件夹。
  2. 进入 DogeFetch 文件夹，双击 DogeFetch.exe。
  3. 选择保存目录，粘贴链接后下载，或加入队列批量处理。

支持的单视频平台包括 YouTube、B站、抖音、皮皮虾、小红书和快手，具体可用性受平台和解析组件影响。抖音解析使用第三方服务，会向其发送视频链接。

DOGEGIF / V1.0.0

DogeGif · 视频转 GIF 工具

将视频片段转换成 GIF 动图，适合制作操作演示、分享精彩画面。v1.0.0 为 Windows x64 免安装版，界面使用简体中文，可切换浅色与深色主题。

可以做什么

  • 预览视频，输入起止时间或用当前画面设置片段起点与终点。
  • 调整输出宽度、帧率和颜色优化方式，高度按视频比例计算。
  • 使用日常分享、小巧省空间、清晰更流畅三种快捷方案。
  • 设置循环播放，查看转换进度，按需取消转换。
  • 导出后预览 GIF，并一键打开保存文件夹。

开始使用

  1. 将整个压缩包解压到普通文件夹，双击 DogeGif.exe。
  2. 点击「选择视频」，设置开始与结束时间。
  3. 调整画面宽度、帧率及颜色优化，点击「生成 GIF」选择保存位置。

转换在本机完成，无需上传视频。支持 MP4、MOV、MKV、AVI、WebM 等常见视频；部分编码可能无法在内置播放器预览，但仍可尝试转换。单次片段最长 300 秒，建议先选取 3–10 秒，尺寸和帧率越大，文件通常越大。

DOGEKEY / V1.3

DogeKey · 窗口快捷控制

用快捷键隐藏或呼出指定应用窗口。支持按应用关联全部窗口，也可以切换到全部窗口视图，仅控制选中的窗口。

F9 控制目标窗口F8 隐藏或呼出自身Windows 10 / 11

使用方法

  1. 运行 DogeKey.exe，刷新应用列表。
  2. 选中目标应用并关联；需要时切换为仅控制所选窗口。
  3. 按 F9 隐藏或呼出目标，按 F8 隐藏或呼出 DogeKey 主窗口和托盘图标。

每次启动需要重新关联。隐藏不会暂停程序或停止声音，也不会移除目标自己的托盘图标。正常退出或解除关联会恢复窗口，请避免强制结束。目标以管理员身份运行时，DogeKey 也需以管理员身份运行。
