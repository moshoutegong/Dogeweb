# Doge 软件小站

Doge 系列软件的介绍与下载网站，包含 DogeFetch、DogeGif、DogeRecord，以及 DogeERP、DogeKey 等其他软件和修改项目。

## 本地查看

完整下载后打开 `index.html` 即可，无需安装依赖或构建。

## 部署

将 `index.html` 与 `assets` 一起上传至静态网站托管服务。也可以使用 GitHub Pages，从 main 分支的根目录发布。

## 文件

- `index.html`：页面、样式与交互源码。
- `assets/`：品牌图标、演示动图和展示图片。

网站只提供软件介绍及网盘下载入口，不包含软件安装包。
